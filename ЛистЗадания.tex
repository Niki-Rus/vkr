	3. Исходные данные для создания программной системы:
	
	3.1. Перечень решаемых задач:}

\renewcommand\labelenumi{\theenumi)}

\begin{enumerate}
	\item изучить принципы работы алгоритма симметричного шифрования AES-128;
	\item спроектировать архитектуру программной библиотеки на языке Common Lisp;
	\item реализовать базовые криптографические преобразования (SubBytes, ShiftRows, MixColumns) и алгоритм расширения ключа;
	\item разработать механизмы дополнения данных (PKCS\#7) для обработки сообщений произвольной длины;
	\item провести тестирование корректности процессов шифрования и дешифрования.
\end{enumerate}

{\parindent0pt
	3.2. Входные данные и требуемые результаты для программы:}

\begin{enumerate}
	\item Входными данными являются: массив байтов исходного сообщения произвольной длины; секретный ключ шифрования длиной 128 бит (16 байт); массив зашифрованных данных (для операции дешифрования).
	\item Выходными данными являются: массив зашифрованных байтов; восстановленное исходное сообщение после дешифрования; результаты автоматического тестирования, подтверждающие корректность работы алгоритма.
\end{enumerate}
