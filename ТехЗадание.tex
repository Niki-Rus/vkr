\section{Техническое задание}
\subsection{Основание для разработки}

Основанием для разработки является задание по курсовой работе 
<<Разработка программной библиотеки для шифрования данных по стандарту AES-128 на языке Common Lisp>>. 

\subsection{Цель и назначение разработки}

Целью курсовой работы является разработка программной библиотеки для шифрования данных по стандарту AES-128.  

Разработка библиотеки направлена на получение практических навыков проектирования алгоритмов, а также на формирование базы для последующего применения в системах защиты информации.  

Задачами данной разработки являются:
\begin{itemize}
	\item изучение принципов работы алгоритма AES;
	\item разработка требований к библиотеке;
	\item проектирование структуры модулей библиотеки; 
	\item реализация функций шифрования и дешифрования;
	\item тестирование разработанных функций.
\end{itemize}

\subsection{Функции библиотеки}

Библиотека должна включать в себя следующие функции:
\begin{itemize}
	\item функция для шифрования данных по алгоритму AES-128 (с поддержкой дополнения PKCS\#7);
	\item функция для дешифрования данных.
\end{itemize}

\subsection{Описание программного интерфейса}

Программная библиотека включает в себя следующие основные компоненты:

\begin{enumerate}
	\item \textbf{Функции шифрования:}
	\begin{itemize}
		\item на входе: массив открытых данных произвольной длины, ключ шифрования (128 бит);
		\item выполняет: дополнение данных до кратности блоку (PKCS\#7), разбиение на блоки, раундовые преобразования шифрования;
		\item на выходе: массив зашифрованных байтов.
	\end{itemize}
	
	\item \textbf{Функции дешифрования:}
	\begin{itemize}
		\item на входе: массив зашифрованных данных, ключ шифрования (128 бит);
		\item выполняет: обратные раундовые преобразования, удаление дополнения (unpad);
		\item на выходе: восстановленный массив исходных данных.
	\end{itemize}
	
	\item \textbf{Функции работы с ключами:}
	\begin{itemize}
		\item расширение исходного ключа пользователя;
		\item генерация набора раундовых ключей для каждого этапа шифрования.
	\end{itemize}
\end{enumerate}
