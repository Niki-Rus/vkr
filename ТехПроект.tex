\section{Технический проект}

\subsection{Описание функции шифрования}

Имя функции: encrypt-block

Описание интерфейса:
\begin{itemize}
	\item Входные параметры:
	\begin{itemize}
		\item data — блок данных для шифрования (16 байт);
		\item round-keys — набор подготовленных ключей для каждого раунда.
	\end{itemize}
	\item Возвращаемое значение: зашифрованный блок данных (16 байт).
	\item Назначение: выполняет шифрование блока данных по стандарту AES-128.
\end{itemize}

\subsection{Описание функции дешифрования}

Имя функции: decrypt-block

Описание интерфейса:
\begin{itemize}
	\item Входные параметры:
	\begin{itemize}
		\item data — зашифрованный блок данных (16 байт);
		\item round-keys — набор ключей в обратном порядке.
	\end{itemize}
	\item Возвращаемое значение: расшифрованный блок (16 байт).
	\item Назначение: выполняет обратные алгоритмические преобразования для восстановления исходного блока данных из зашифрованного состояния.
\end{itemize}

\subsection{Структуры данных}

Для представления информации в программе используются векторы (массивы), состоящие из 8-битных целых чисел без знака. Данная структура позволяет хранить каждый байт блока данных или ключа в отдельной ячейке памяти, что обеспечивает удобный доступ к данным при выполнении раундовых преобразований.
