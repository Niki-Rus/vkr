\section{Технический проект}

\subsection{Основные структуры данных}
Для реализации алгоритма AES в программе используются следующие статические структуры данных:
\begin{itemize}
	\item Таблица прямой замены (S-box) — массив из 256 байтов, используемый для нелинейной замены байтов при шифровании;
	\item Таблица обратной замены (Inverse S-box) — массив из 256 байтов, используемый при дешифровании;
	\item Раундовые константы (Rcon) — массив значений, используемый в процессе генерации ключей для внесения асимметрии.
\end{itemize}

\subsection{Функция расширения ключа (key-expansion)}
Входные параметры:
\begin{itemize}
	\item{key} — исходный ключ шифрования (вектор 16 байт).
\end{itemize}

Выходные данные: вектор раундовых ключей.

Назначение: генерация полного набора ключей из одного секретного ключа, необходимых для всех раундов шифрования.


\subsection{Функция дополнения данных (pkcs7-pad)}
Входные параметры:
\begin{itemize}
	\item{data} — исходный вектор байтов произвольной длины.
\end{itemize}

Выходные данные: новый вектор, длина которого кратна 16 байтам.

Назначение: подготовка данных к блочному шифрованию путем добавления байтов-заполнителей согласно стандарту PKCS\#7.


\subsection{Функция удаления дополнения (pkcs7-unpad)}
Входные параметры:
\begin{itemize}
	\item{data} — вектор расшифрованных байтов.
\end{itemize}

Выходные данные: вектор байтов исходной длины.

Назначение: удаление байтов-заполнителей после дешифрования для восстановления оригинального сообщения.


\subsection{Функция шифрования блока (encrypt-block)}
Входные параметры:
\begin{itemize}
	\item{data} — блок данных (16 байт);
	\item{key} — ключ шифрования.
\end{itemize}

Выходные данные: зашифрованный блок (16 байт).

Назначение: низкоуровневая реализация 10 раундов AES (SubBytes, ShiftRows, MixColumns, AddRoundKey).


\subsection{Функция шифрования данных (encrypt-data)}
Входные параметры:
\begin{itemize}
	\item{data} — вектор исходных данных произвольной длины;
	\item{key} — ключ шифрования.
\end{itemize}

Выходные данные: вектор зашифрованных данных.

Назначение: основной цикл шифрования. Выполняет дополнение данных (pad), разбивку на блоки и применение функции encrypt-block.


\subsection{Функция дешифрования блока (decrypt-block)}
Входные параметры:
\begin{itemize}
	\item{data} — зашифрованный блок (16 байт);
	\item{key} — ключ шифрования.
\end{itemize}

Выходные данные: расшифрованный блок (16 байт).

Назначение: низкоуровневая реализация обратных преобразований AES для одного блока.


\subsection{Функция дешифрования данных (decrypt-data)}
Входные параметры:
\begin{itemize}
	\item{data} — вектор зашифрованных данных;
	\item{key} — ключ шифрования.
\end{itemize}

Выходные данные: вектор исходных данных.

Назначение: основной цикл дешифрования. Выполняет обработку блоков функцией decrypt-block и финишное удаление дополнения (unpad).


\subsection{Функция запуска тестов (run-tests)}
Входные параметры:
\begin{itemize}
	\item отсутствуют (используются встроенные тестовые векторы).
\end{itemize}

Выходные данные: вывод результатов в консоль (сравнение оригинальных и дешифрованных данных).

Назначение: проверка корректности всей библиотеки путем шифрования и дешифрования сообщений разной длины.
